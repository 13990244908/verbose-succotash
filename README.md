# Python 基础语法：动手跑一遍

《统计与数据分析》上机前的语法铺垫。五个文件，按顺序跑完即可覆盖后面数据分析要用到的全部语法地基。

示例全部取自**广告投放与统计分析**场景（曝光、点击率 CTR、千次曝光成本 CPM、投资回报率 ROI、渠道组合），学完直接能用在课程数据集上。

**纯标准库、零依赖、不联网、不读键盘输入**，输出每次完全一致——方便对照，也方便课堂投屏演示。

---

## 怎么跑

在 VSCode 里打开本文件夹，任选一种：

| 方式 | 操作 |
| --- | --- |
| 单文件运行 | 打开 `.py` 文件，点右上角 ▶ Run Python File，或按 `Ctrl + F5` |
| 终端运行 | `python 01_variables.py` |
| 逐行看变量 | 在行号左侧点一下打断点，按 `F5`，用调试面板看每一步的值 |

**顺序建议：`01` → `05`，不要跳。** `03` 的推导式和 `05` 的 `lambda` 都用到了前面文件的概念。

## 每个文件长什么样

五个文件结构一致，读起来不用重新适应：

1. **顶部文档字符串**：学习目标 + 运行方法。
2. **`# ==== N. 小节标题 ====`** 分节。每节先写「为什么」和「是什么」，再给可运行的代码，关键结果的行尾用 `# -> 结果` 标出实际输出。
3. 每节末尾一行 **`# 【动手改】`**：改一个地方再看结果——比只读代码有用得多。
4. 文末 **`# ===== 练习 =====`**：4 道题，每题附验证方式（跑出来应该是什么）。
5. 文末 **`# ===== 参考答案 =====`**：可运行的解答。

> 想先自己做练习，就把「参考答案」那一段整体注释掉再运行。

## 容易踩的坑（本套资料专门讲了的）

| 坑 | 出现在 |
| --- | --- |
| `-7 // 2` 是 `-4` 不是 `-3`（向下取整） | 02 第 1 节 |
| `0.1 + 0.2 != 0.3`（浮点误差，要用 `math.isclose`） | 02 第 2 节 |
| `and`/`or` 返回的是操作数，不是 True/False | 02 第 3 节 |
| `{}` 是空字典，空集合要写 `set()` | 01 第 4 节 |
| `b = a` 不复制列表，改 b 会连带改 a（别名陷阱） | 03 第 7 节 |
| `def f(x, lst=[])` 的默认值会被多次调用共用 | 05 第 3 节 |
| 遍历列表的同时删元素会漏掉元素 | 04 第 8 节 |
| 循环里定义的 lambda 会在调用时才取值 | 04 第 8 节 |

## 学习建议

- **不要只读，要动手改**：每个小节末尾的 `# 【动手改】` 就是给你准备的
- 先做完文末练习，再对照参考答案
- 遇到报错认真读错误信息——这是成长最快的方式
- 跑完 01～05 后，找一份真实数据集（CSV）试着算一遍 CTR 和 CPM
