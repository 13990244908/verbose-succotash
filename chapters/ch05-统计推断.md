# 第 5 章 统计推断：抽样分布与置信区间

现实中，我们几乎永远拿不到「全部」数据——比如全中国人的身高。我们能做的，是抽取一个**样本**，然后用样本去**推断**总体。这就是**统计推断**。

本章解决两个核心概念：**抽样分布**和**置信区间**。

## 5.1 总体、样本与统计量

- **总体（Population）**：你想研究的全体，比如「全校学生」。
- **样本（Sample）**：从总体中抽出来的一部分，比如「随机抽的 200 名学生」。
- **统计量（Statistic）**：由样本算出来的数，如样本均值。它是用来估计总体参数的。

| | 总体参数 | 样本统计量 |
| --- | --- | --- |
| 均值 | μ（真值，通常未知） | x̄（样本均值，可算） |
| 标准差 | σ | s |

> 习惯上，总体参数用希腊字母（μ、σ），样本统计量用英文字母（x̄、s）。

## 5.2 抽样分布与中心极限定理

想象一下：你反复从总体中抽取很多个「大小相同」的样本，每个样本都能算一个均值 x̄。这些 x̄ 又构成一个新的分布——**抽样分布**。

**中心极限定理（CLT）** 是统计学的基石，它说：

> 只要样本量 n 足够大（通常 n ≥ 30），**无论总体是什么分布**，样本均值的抽样分布都近似服从**正态分布**，且：
>
> - 抽样分布的均值 ≈ 总体均值 μ；
> - 抽样分布的标准差 = σ / √n，这个值叫**标准误（Standard Error, SE）**。

第 4 章的代码已经直观演示过这一点：30 个均匀随机数的均值，反复抽取后，分布就变成了钟形。

### 标准误的作用

标准误 `SE = σ / √n` 衡量「样本均值有多精确」。**n 越大，SE 越小**，估计越精确。这也是为什么样本越大越可信。

## 5.3 置信区间（Confidence Interval）

既然样本均值只是「估计」，那它离真值 μ 有多远？**置信区间**就是给出一个「有把握」的范围。

> **95% 置信区间**的含义：如果重复抽样 100 次，每次算一个区间，大约有 95 个区间会包含真实的总体均值 μ。

在总体标准差已知、或样本足够大时，均值的 95% 置信区间近似为：

```
x̄ ± 1.96 × (σ / √n)
```

（`1.96` 正是标准正态分布 95% 概率对应的分位点，见第 4 章。）

### 更严谨的做法：t 分布

当样本较小、且用样本标准差 s 代替 σ 时，应该用 **t 分布**而不是正态分布。t 分布比正态分布「尾巴更厚」，自由度越小越明显。

```python
from scipy import stats
import numpy as np

sample = [85, 90, 78, 92, 88, 79, 95, 83]
n = len(sample)
xbar = np.mean(sample)
s = np.std(sample, ddof=1)          # 样本标准差
se = s / np.sqrt(n)                 # 标准误

# 95% 置信区间（t 分布）
t_crit = stats.t.ppf(0.975, df=n-1)
ci_low = xbar - t_crit * se
ci_high = xbar + t_crit * se
print(f"均值 95% 置信区间：[{ci_low:.2f}, {ci_high:.2f}]")
```

## 5.4 影响置信区间宽窄的因素

| 因素 | 变化 | 区间宽度 |
| --- | --- | --- |
| 样本量 n 增大 | 标准误变小 | 变窄（更精确） |
| 置信水平提高（95%→99%） | 分位点变大 | 变宽 |
| 数据越分散（s 大） | 标准误变大 | 变宽 |

## 5.5 本章小结

- 统计推断：用样本统计量去估计总体参数。
- 中心极限定理：样本量足够大时，样本均值近似正态，标准误 = σ/√n。
- 置信区间：给出总体均值的可信范围，95% 是常用水平。
- 小样本用 t 分布更严谨。
