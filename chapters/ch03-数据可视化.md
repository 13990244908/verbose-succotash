# 第 3 章 数据可视化

数字虽然精确，但对人来说，**一张图往往比一百个数字更直观**。这一章我们用 Python 最常用的绘图库 **Matplotlib**，把数据「画」出来。

## 3.1 Matplotlib 快速上手

```python
import matplotlib.pyplot as plt   # 习惯简称 plt

x = [1, 2, 3, 4, 5]
y = [2, 4, 6, 8, 10]

plt.plot(x, y)        # 画折线图
plt.xlabel("x")       # 横轴标签
plt.ylabel("y")       # 纵轴标签
plt.title("示例图")    # 标题
plt.show()            # 显示图形
```

在 Jupyter 或脚本里，`plt.show()` 会弹出图形窗口；如果没显示，可能需要先加一行 `%matplotlib inline`（Jupyter）或把图保存为文件（见下）。

## 3.2 四种最常用的图

### 3.2.1 直方图（Histogram）

看**一个连续变量**的分布，比如「数学成绩大致落在哪个区间的人最多」。

```python
plt.hist(df["数学"], bins=20, color="skyblue", edgecolor="black")
plt.xlabel("数学成绩")
plt.ylabel("人数")
plt.title("数学成绩分布")
plt.show()
```

### 3.2.2 箱线图（Box Plot）

用「五数概括」（最小值、Q1、中位数、Q3、最大值）展示分布，还能一眼看出**离群点**。

```python
plt.boxplot(df["数学"])
plt.ylabel("数学成绩")
plt.title("数学成绩箱线图")
plt.show()
```

箱线图里，箱子中间的线是中位数，箱子上下边是 Q1 和 Q3，两头「胡须」延伸到正常范围，超出胡须的点是可能的异常值。

### 3.2.3 散点图（Scatter Plot）

看**两个连续变量之间有没有关系**，比如「数学成绩和英语成绩是否相关」。

```python
plt.scatter(df["数学"], df["英语"], alpha=0.6)
plt.xlabel("数学")
plt.ylabel("英语")
plt.title("数学 vs 英语")
plt.show()
```

### 3.2.4 柱状图 / 条形图（Bar Chart）

比较**分类**的数值，比如「各专业的人数」或「各品类销售额」。

```python
counts = df["专业"].value_counts()
plt.bar(counts.index, counts.values, color="orange")
plt.xlabel("专业")
plt.ylabel("人数")
plt.title("各专业人数")
plt.show()
```

## 3.3 中文显示问题

Matplotlib 默认字体不含中文，图上中文会显示成方块。解决办法是设置中文字体：

```python
import matplotlib
matplotlib.rcParams["font.sans-serif"] = ["Microsoft YaHei", "SimHei"]  # 微软雅黑/黑体
matplotlib.rcParams["axes.unicode_minus"] = False   # 解决负号显示为方块
```

> Windows 下一般装好就有「Microsoft YaHei」；如果你在 macOS/Linux，可换成系统里已有的中文字体。

## 3.4 保存图片

不想弹窗，也可以直接把图存成文件：

```python
plt.savefig("fig.png", dpi=150)   # 保存为 PNG，dpi 越高越清晰
```

## 3.5 可视化原则小结

- **选对图型**：分布→直方图/箱线图；关系→散点图；分类对比→柱状图；趋势→折线图。
- **标注齐全**：标题、坐标轴标签、单位、图例一个都不能少。
- **别过度装饰**：图是拿来「说事」的，不是拿来炫技的。

## 3.6 本章小结

- Matplotlib 是 Python 基础绘图库，`plt` 是习惯简称。
- 四种基础图：直方图、箱线图、散点图、柱状图，各有适用场景。
- 中文需要设置字体，负号要单独处理。
