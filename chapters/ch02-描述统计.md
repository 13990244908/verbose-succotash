# 第 2 章 描述统计：集中趋势与离散程度

拿到一份数据后，第一件事不是画花哨的图，而是先「看懂它大概长什么样」。**描述统计**就是用几个数字，把数据的样子概括出来。

它主要回答两类问题：

1. **集中趋势**：数据「中心」在哪？（均值、中位数、众数）
2. **离散程度**：数据「散得有多开」？（方差、标准差、极差、四分位数）

## 2.1 集中趋势

### 2.1.1 均值（Mean）

最常用的「平均数」，所有数值加起来除以个数。

```
均值 = (x₁ + x₂ + ... + xₙ) / n
```

```python
scores = [85, 90, 78, 92]
mean = sum(scores) / len(scores)   # 手算
print(mean)                          # 86.25
```

**均值的问题**：容易被极端值「带偏」。比如 5 个人收入分别是 `[5000, 5200, 4800, 5300, 100000]`，均值会被那个 10 万拉到 2 万多，无法代表大多数人。

### 2.1.2 中位数（Median）

把数据从小到大排好，**正中间**的那个数。如果偶数个，取中间两个的平均。

```python
scores = [85, 90, 78, 92]
scores.sort()
# 排序后 [78, 85, 90, 92]，中间两个是 85 和 90
median = (85 + 90) / 2              # 87.5
print(median)
```

中位数**不怕极端值**，所以在收入、房价这类「分布很偏」的数据里，中位数往往比均值更有代表性。

### 2.1.3 众数（Mode）

出现次数最多的值。一组数据可以没有众数，也可以有多个。

### 2.1.4 什么时候用哪个？

| 指标 | 优点 | 缺点 | 适用场景 |
| --- | --- | --- | --- |
| 均值 | 用了所有数据，计算方便 | 怕极端值 | 分布对称的数据 |
| 中位数 | 稳健，不怕极端值 | 没用全所有数据 | 偏态、有异常值 |
| 众数 | 直观 | 信息量少 | 分类数据 |

## 2.2 离散程度

只看「中心」不够。比如两组数据均值都是 50，但一组是 `[49, 50, 51]`（很集中），另一组是 `[10, 50, 90]`（很分散），它们完全不同。所以还要看「离散程度」。

### 2.2.1 极差（Range）

最大值减最小值。简单但只用了两个数，容易受异常值影响。

```
极差 = 最大值 - 最小值
```

### 2.2.2 方差与标准差（Variance & Standard Deviation）

衡量每个数据偏离均值的「平均」程度。

```
方差 = Σ(xᵢ - 均值)² / n        （总体方差）
标准差 = √方差
```

标准差和原始数据单位一致，所以更常被使用。**标准差越大，数据越分散。**

```python
import statistics
scores = [85, 90, 78, 92]
print("标准差：", statistics.stdev(scores))   # 样本标准差
```

> 小知识：计算样本（不是全体）时，方差分母是 `n-1`，这叫「样本方差」，Pandas 和 `statistics.stdev` 默认都用 `n-1`。我们课程里的数据都当作样本处理。

### 2.2.3 四分位数与 IQR

把排序后的数据四等分，得到三个切分点：

- **Q1（下四分位数）**：25% 位置
- **Q2（中位数）**：50% 位置
- **Q3（上四分位数）**：75% 位置

**四分位距 IQR = Q3 - Q1**，衡量中间 50% 数据的跨度，也不怕极端值。

## 2.3 用 Pandas 一键计算

实际工作中，直接用 Pandas 的 `describe()`：

```python
import pandas as pd
df = pd.read_csv("data/students.csv")
print(df[["数学", "英语", "编程"]].describe())
```

输出会包含：`count`（个数）、`mean`（均值）、`std`（标准差）、`min`、`25%/50%/75%`（四分位数）、`max`。

### 常用命令速查

| 命令 | 作用 |
| --- | --- |
| `df["列"].mean()` | 均值 |
| `df["列"].median()` | 中位数 |
| `df["列"].mode()` | 众数 |
| `df["列"].std()` | 样本标准差 |
| `df["列"].var()` | 样本方差 |
| `df["列"].max()` / `.min()` | 最大 / 最小值 |
| `df["列"].quantile(0.25)` | 下四分位数 |
| `df["列"].quantile(0.75)` | 上四分位数 |

## 2.4 本章小结

- 集中趋势：均值（怕极端值）、中位数（稳健）、众数。
- 离散程度：极差、方差/标准差、四分位距 IQR。
- Pandas 的 `describe()` 一次给出全套描述统计。
