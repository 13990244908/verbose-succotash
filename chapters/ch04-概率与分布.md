# 第 4 章 概率与常见分布

前面几章都在描述「已经拿到手的数据」。但统计更深层的任务，是**从样本推断总体**。要理解推断，先要懂一点**概率**和**概率分布**。

## 4.1 概率的基本概念

**概率（Probability）**：刻画一个事件发生的可能性，取值在 0 到 1 之间。

- `0`：一定不发生
- `1`：一定发生
- `0.5`：发生和不发生的可能性各半

例如掷一枚均匀硬币，出现正面的概率是 `0.5`。

### 事件与概率法则

- 任意事件概率 `P(A)` 满足 `0 ≤ P(A) ≤ 1`。
- 所有可能结果概率之和为 1。
- 互斥事件（不能同时发生）的概率可相加。

## 4.2 随机变量

**随机变量**：把随机试验的结果映射成数值。比如「掷一次骰子的点数」就是一个随机变量。

随机变量分两类：

- **离散型**：取值可数，如骰子点数（1~6）、某天来店人数。
- **连续型**：取值连续，如身高、体重、时间。

## 4.3 离散分布：二项分布

**二项分布**描述「做 n 次独立试验，每次成功概率为 p，成功次数」的分布。典型例子：抛 10 次硬币，正面朝上几次？

```python
from scipy.stats import binom
# 抛 10 次硬币，正面概率 0.5，恰好出现 6 次正面的概率
print(binom.pmf(6, n=10, p=0.5))   # 约 0.205
```

- `binom.pmf(k, n, p)`：恰好成功 k 次的概率。
- `binom.cdf(k, n, p)`：成功不超过 k 次的累积概率。

## 4.4 连续分布：正态分布

**正态分布**（Normal distribution，又叫高斯分布）是统计里最重要的分布，形状像一座「钟」，中间高、两边低、左右对称。

它由两个参数决定：

- **均值 μ**：钟的「中心」位置。
- **标准差 σ**：钟的「胖瘦」，σ 越大越扁平。

```
f(x) = 1 / (σ√(2π)) · exp( -(x-μ)² / (2σ²) )
```

### 为什么正态分布这么重要？

1. 很多自然现象（身高、体重、测量误差）都近似正态。
2. **中心极限定理**（下一章）告诉我们：大量独立随机变量的均值，往往趋近正态分布。

### 用 Python 画正态分布

```python
import numpy as np
import matplotlib.pyplot as plt
from scipy.stats import norm

x = np.linspace(-4, 4, 500)
y = norm.pdf(x, loc=0, scale=1)   # 标准正态：均值 0，标准差 1

plt.plot(x, y)
plt.title("标准正态分布")
plt.show()
```

### 68-95-99.7 法则

对正态分布：

- 约 **68%** 的数据落在 `μ ± 1σ` 内；
- 约 **95%** 落在 `μ ± 2σ` 内；
- 约 **99.7%** 落在 `μ ± 3σ` 内。

这个法则在后面「置信区间」和「假设检验」里会反复用到。

### 计算正态分布概率

```python
from scipy.stats import norm
# 标准正态下，取值小于 1.96 的概率
print(norm.cdf(1.96))              # 约 0.975

# 落在 (-1.96, 1.96) 之间的概率
print(norm.cdf(1.96) - norm.cdf(-1.96))   # 约 0.95
```

## 4.5 SciPy 常用分布速查

| 分布 | 类型 | `scipy.stats` 函数 | 用途 |
| --- | --- | --- | --- |
| 二项分布 | 离散 | `binom` | 成功次数 |
| 正态分布 | 连续 | `norm` | 身高、误差等 |
| t 分布 | 连续 | `t` | 小样本推断 |
| 均匀分布 | 连续 | `uniform` | 等可能取值 |

常用方法：`.pmf()`（离散概率）、`.pdf()`（连续密度）、`.cdf()`（累积概率）。

## 4.6 本章小结

- 概率刻画事件发生的可能性，取值 0~1。
- 二项分布：n 次独立试验的成功次数。
- 正态分布由均值 μ 和标准差 σ 决定，是统计学的核心分布。
- 68-95-99.7 法则要记牢，后面两章全靠它。
