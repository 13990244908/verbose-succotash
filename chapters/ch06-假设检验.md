# 第 6 章 假设检验

上一章我们用样本去「估计」总体参数。这一章我们反过来：先提出一个「假设」，再用数据去判断它**是否成立**。这就是**假设检验**。

## 6.1 一个例子：硬币公平吗？

假设你怀疑一枚硬币被做了手脚。于是你抛了 100 次，得到 60 次正面。这枚硬币公平吗？

直觉上「60 次正面」有点多，但也不一定有问题——公平硬币抛 100 次，偶尔 60 次正面也完全可能。假设检验就是用一个**标准化的判断流程**，来量化「到底有多不可能」。

## 6.2 两个假设

- **原假设 H₀（Null hypothesis）**：默认成立的、要被检验的「无差别」假设。例：硬币公平，正面概率 p = 0.5。
- **备择假设 H₁（Alternative hypothesis）**：与原假设对立的说法。例：硬币不公平，p ≠ 0.5。

> 记法：`H₀: p = 0.5` 对 `H₁: p ≠ 0.5`（双侧检验）。

我们的逻辑是：**先假定 H₀ 成立，看数据有多「反常」；如果反常到一定程度，就拒绝 H₀，接受 H₁。**

## 6.3 p 值

**p 值（p-value）**：在 H₀ 成立的前提下，观察到「当前数据或更极端情况」的概率。

- p 值**小** → 数据很反常 → 倾向于拒绝 H₀。
- p 值**大** → 数据不反常 → 不能拒绝 H₀。

判断标准是事先定好的**显著性水平 α**（常用 0.05）：

```
若 p < α（如 0.05） → 拒绝 H₀，结果「显著」
若 p ≥ α           → 不能拒绝 H₀
```

> 注意：「不能拒绝 H₀」不等于「H₀ 一定正确」，只是证据不足。类似法庭上「证据不足，无罪」不等于「确定无辜」。

## 6.4 单样本 t 检验

检验「一组数据的均值」是否等于某个目标值。例如：某校声称全校数学平均分是 75，我们抽了 50 个样本，均值是 78，差异显著吗？

```python
from scipy import stats
import pandas as pd

df = pd.read_csv("data/students.csv")
sample = df["数学"].sample(50, random_state=1)

t_stat, p_value = stats.ttest_1samp(sample, popmean=75)
print(t_stat, p_value)
```

- 若 `p_value < 0.05`：拒绝「均值=75」，说明差异显著。
- 若 `p_value >= 0.05`：不能拒绝，样本均值与 75 的差异可归因于随机波动。

## 6.5 双样本 t 检验

检验「两组数据的均值」是否相等。例如：男生和女生的数学成绩有没有显著差异？

```python
male = df[df["性别"] == "男"]["数学"]
female = df[df["性别"] == "女"]["数学"]

t_stat, p_value = stats.ttest_ind(male, female)
print(t_stat, p_value)
```

- 若 `p_value < 0.05`：两组均值有显著差异。
- 若 `p_value >= 0.05`：不能说明有差异。

## 6.6 卡方检验（分类数据）

t 检验针对「数值型」数据；对于「分类」数据（如性别、专业），要看两个分类是否**相关**，用**卡方检验**。

例如：不同专业的学生，性别比例是否不同？（即「专业」和「性别」是否独立）

```python
import pandas as pd
from scipy.stats import chi2_contingency

df = pd.read_csv("data/students.csv")
table = pd.crosstab(df["专业"], df["性别"])   # 列联表

chi2, p_value, dof, expected = chi2_contingency(table)
print(chi2, p_value)
```

- 若 `p_value < 0.05`：拒绝「两变量独立」，说明专业与性别相关。
- 若 `p_value >= 0.05`：不能说明相关。

## 6.7 两类错误

假设检验不是万无一失的，可能犯两类错误：

| | 实际 H₀ 为真 | 实际 H₀ 为假 |
| --- | --- | --- |
| 结论：拒绝 H₀ | **第一类错误**（α，冤枉好人） | 正确 |
| 结论：不拒绝 H₀ | 正确 | **第二类错误**（β，放过坏人） |

- **第一类错误**：H₀ 本来成立，却错误地拒绝了它。概率等于显著性水平 α。
- **第二类错误**：H₀ 不成立，却没拒绝它。样本量越大，越不容易犯这类错误。

## 6.8 检验方法选择速查

| 数据 / 问题 | 用什么检验 |
| --- | --- |
| 一组数值 vs 目标值 | 单样本 t 检验 |
| 两组数值均值比较 | 双样本 t 检验 |
| 多组数值均值比较 | 方差分析（ANOVA，进阶） |
| 两个分类变量是否相关 | 卡方检验 |

## 6.9 本章小结

- 假设检验：先设 H₀，用 p 值判断是否拒绝。
- p 值 < α（0.05）→ 拒绝 H₀，结果显著。
- 数值比较用 t 检验，分类相关性用卡方检验。
- 可能犯两类错误，理解「不拒绝 ≠ 确定成立」。
