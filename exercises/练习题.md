# 参考答案

## 01 变量

### 参考答案 1

```python
book_name = "Python 基础"
price = 59.9
in_stock = True

print(book_name, type(book_name))
print(price, type(price))
print(in_stock, type(in_stock))
```

### 参考答案 2

输出：

```
十
```

因为 Python 变量可以被重新赋值为不同类型。

### 参考答案 3

- `userName`：合法，但不推荐。Python 风格推荐 `user_name`（小写 + 下划线）。
- `2nd_user`：不合法，不能以数字开头。
- `_private`：合法，以单下划线开头通常表示“私有”约定。
- `class`：不合法，`class` 是 Python 关键字。

### 参考答案 4

```python
fruits = ["苹果", "香蕉", "橙子"]        # list
point = (3, 5)                          # tuple
nums = {1, 2, 2, 3}                     # set
student = {"姓名": "张三", "年龄": 20}    # dict

print(fruits, type(fruits))
print(point, type(point))
print(nums, type(nums))        # 输出 {1, 2, 3}，重复的 2 被自动去掉
print(student, type(student))
```

`{}` 创建出来的是**空字典**，不是空集合。空集合必须写 `set()`：

```python
print(type({}))       # <class 'dict'>
print(type(set()))    # <class 'set'>
```

### 参考答案 4

```python
print(-7 // 2)       # -4
print(int(-7 / 2))   # -3
```

**为什么不同**：`//` 是向下取整（往数轴更小的方向取，所以 -3.5 → -4）；`int()` 是直接砍掉小数部分（往 0 的方向取，所以 -3.5 → -3）。正数时两者结果相同，负数时才看出差别。

取余判断能否整除：

```python
print(2026 % 4)         # 2
print(2026 % 4 == 0)    # False，2026 不能被 4 整除
print(2024 % 4 == 0)    # True，2024 能被 4 整除
```

## 05 函数

### 参考答案 1

```python
def say_hello(name):
    print(f"你好，{name}！")

say_hello("张三")
```

### 参考答案 2

```python
def is_even(n):
    return n % 2 == 0

print(is_even(4))  # True
print(is_even(7))  # False
```

### 参考答案 3

```python
def sum_all(*numbers):
    total = 0
    for n in numbers:
        total += n
    return total

print(sum_all(1, 2, 3, 4))
```

### 参考答案 4

```python

describe_book("Python 进阶", "王五", 89.0)
```
