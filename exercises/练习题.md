**2. [1,2,3,4,100] 的均值与标准差**

```python
import numpy as np
data = np.array([1, 2, 3, 4, 100])
print("均值：", data.mean())    # 22.0
print("标准差：", data.std())   # 约 38.7
```

把 100 换成 5 后，均值从 22 降到 3，大幅变化。说明**均值对极端值敏感**，而中位数（3）不变，更稳健。

**2. 标准正态下大于 1.96 的概率**

```python
from scipy.stats import norm
print(1 - norm.cdf(1.96))          # 约 0.025
```

**3. 解释**
标准差 σ 越大，数据越分散，正态分布的「钟」就被拉得越宽、越扁平（总面积恒为 1）。

## 第 5 章

**1. 50 名学生数学均值的 95% 置信区间**

```python
import pandas as pd
import numpy as np
from scipy import stats

df = pd.read_csv("data/students.csv")
sample = df["数学"].sample(50, random_state=1)
n = len(sample)
xbar = sample.mean()
se = sample.std(ddof=1) / np.sqrt(n)
t = stats.t.ppf(0.975, df=n-1)
print(f"[{xbar - t*se:.2f}, {xbar + t*se:.2f}]")
```

**2. 区间会变宽**
置信水平越高，分位点越大（如 1.96 → 2.58），区间越宽。

**3. 解释**
样本量 n 越大，标准误 σ/√n 越小，样本均值波动越小，越接近总体均值。

## 第 6 章

**1. 英语均值是否等于 70**

```python
from scipy import stats
import pandas as pd

df = pd.read_csv("data/students.csv")
sample = df["英语"].sample(50, random_state=1)
t_stat, p = stats.ttest_1samp(sample, popmean=70)
print(t_stat, p)   # p < 0.05 则显著
```

**2. 男女编程成绩差异**

```python
male = df[df["性别"] == "男"]["编程"]
female = df[df["性别"] == "女"]["编程"]
t_stat, p = stats.ttest_ind(male, female)
print(t_stat, p)
```

**3. 专业与性别是否相关**

```python
from scipy.stats import chi2_contingency
table = pd.crosstab(df["专业"], df["性别"])
chi2, p, dof, expected = chi2_contingency(table)
print(p)   # p >= 0.05 则不能说明相关
```
